# Artix — Vibe Coding and Prompt Engineering Playbook

Target Release: v1.5.0

---

## 1. Overview and Principles

Vibe Coding in Artix turns high-level feature ideas into file-scoped AI prompts. To prevent AI tools (Cursor, Artix, LLMs) from producing broken code or breaking type contracts, every prompt generated by Artix enforces 4 rules:

1. **Relative File Paths**: Always specify exact file targets (e.g., `src/components/SystemArchitect.tsx`).
2. **Explicit Action Markers**: Mark files clearly with `[NEW]`, `[MODIFY]`, or `[DELETE]`.
3. **No Unverified Assumptions**: Inspect full imports and type signatures before writing code.
4. **Mandatory Verification Steps**: Every generated prompt ends with explicit verification commands (`npx tsc --noEmit` and `npx vitest run`).

## 3. Agentic Workflow Architecture Patterns

Artix supports 6 multi-agent architectural blueprints:

1. **Sequential Pattern**: Chain of agents passing refined outputs step-by-step.
2. **Parallel Fan-Out Pattern**: Distributes sub-tasks across concurrent agents and aggregates results.
3. **Orchestrator-Workers Pattern**: Central coordinator delegating to specialized worker agents.
4. **Router Pattern**: Directs inputs dynamically to specialized agent handlers.
5. **Evaluator-Optimizer Pattern**: Iterative generator-critic loop refining output until quality thresholds are met.
6. **Autonomous ReAct Pattern**: Reasoning + Action loop with tool execution capabilities.
